# 💼 AI Job Application Assistant

A Python-based web application that helps job seekers analyze their resume against a job description and identify matching and missing skills.

## 🚀 Features

- 📄 Upload resume in PDF format
- 📝 Paste a job description
- 🔍 Extract text from resume
- 🎯 Detect required job skills
- ✅ Identify matched skills
- ⚠️ Identify missing skills
- 📊 Calculate resume-job match percentage
- 📋 Track job applications
- 💾 Store application data using SQLite
- 🖥️ Interactive Streamlit interface

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **PyPDF2**
- **SQLite**
- **Pandas**
- **NLP / Text Processing**
- **Git & GitHub**

## ⚙️ How It Works

1. Upload your resume as a PDF.
2. Paste the job description.
3. Click **Analyze Job Match**.
4. The application extracts skills from the resume and job description.
5. It calculates the resume-job match percentage.
6. It displays matched and missing skills.
7. Use the **Job Application Tracker** to save application details.
